# 디지털 소외계층을 위한 사용자 친화적 키오스크

> **MEIT 융합프로젝트 대회 장려상**  
> 전자·기계·IT공학 전공 팀원들과 함께 사용자 접근성을 높인 키오스크 시스템을 개발했습니다.

---

## 📌 Project Overview

기존 키오스크는 디지털 기기에 익숙하지 않은 사용자에게 복잡한 접근 절차와 많은 조작 단계를 요구할 수 있습니다.

본 프로젝트에서는 이러한 문제를 줄이기 위해 기존의 **NFC + 별도 앱 기반 구조를 QR 기반 웹 접속 방식으로 단순화**하고, 브라우저 음성 인식을 적용해 사용자가 보다 쉽게 메뉴를 탐색하고 이용할 수 있도록 설계했습니다.

또한 웹 서비스와 Arduino 기반 음성 출력부를 연결해 사용자의 선택 정보가 실제 하드웨어 기능으로 이어지는 하나의 통합 시스템을 구현했습니다.

---

## 🎯 Goal

- 디지털 소외계층의 키오스크 접근 단계 단순화
- 별도 앱 설치 없이 QR을 통한 빠른 서비스 접근
- 음성 인식을 활용한 사용자 입력 보조
- 메뉴 탐색부터 장바구니·결제까지 기본 키오스크 기능 구현
- 웹과 하드웨어 모듈 간 안정적인 데이터 연동

---

## 💡 Key Idea

### Before

```text
NFC
→ 별도 앱 실행
→ 웹 / 앱 / 하드웨어 간 연동
→ 키오스크 기능 사용
```

초기 구조는 사용자 단계가 많고 시스템 간 통신 구조도 복잡해질 수 있다는 문제가 있었습니다.

### After

```text
QR Scan
→ Web Access
→ Voice / User Input
→ Menu & Cart
→ Payment
→ Arduino Voice Output
```

QR 기반 웹 접속으로 진입 과정을 단순화하고, 필요한 기능을 하나의 흐름으로 연결했습니다.

---

## ⚙️ Main Features

### 1. QR 기반 서비스 접근
- 별도 앱 설치 없이 QR을 통해 웹 서비스 접속
- 사용자 진입 단계 축소

### 2. 브라우저 음성 인식
- 키오스크 조작이 익숙하지 않은 사용자를 위한 음성 입력 기능 적용
- 메뉴 탐색 과정의 사용 부담 완화

### 3. 키오스크 기본 기능
- 메뉴 검색
- 장바구니
- 결제

### 4. Arduino 음성 출력 연동
- 장바구니 확인 단계에서 선택한 메뉴 정보를 하드웨어 음성 출력부와 연결
- 웹의 사용자 선택 결과가 실제 출력 기능으로 이어지도록 구성

---

## 🏗 System Flow

```text
사용자
  ↓
QR 기반 웹 접속
  ↓
메뉴 탐색 / 음성 입력
  ↓
장바구니 및 결제
  ↓
선택 데이터 전달
  ↓
Arduino 음성 출력
```

각 기능을 독립적으로 구현하는 데 그치지 않고, **모듈 간 데이터 형식과 인터페이스를 공통 기준으로 정리**해 전체 시스템이 안정적으로 연동되도록 구성했습니다.

## 🔧 Problem Solving

### 문제 1. 복잡한 초기 접근 구조

초기 NFC와 별도 앱 기반 방식은 사용자에게 여러 단계를 요구하고, 웹·앱·하드웨어 간 통신 구조도 복잡해질 수 있었습니다.

**Solution**
- NFC + 앱 구조를 QR 기반 웹 접속 방식으로 변경
- 별도 앱 설치 과정을 제거해 사용자 접근 흐름 단순화

### 문제 2. 서로 다른 모듈 간 연동

웹 기능과 하드웨어 기능을 각각 구현하더라도 데이터 형식과 인터페이스가 다르면 통합 과정에서 문제가 발생할 수 있었습니다.

**Solution**
- 모듈 간 데이터 형식과 인터페이스를 공통 기준으로 정리
- 기능별 개발 결과를 단계적으로 연결하고 통합 테스트 수행
